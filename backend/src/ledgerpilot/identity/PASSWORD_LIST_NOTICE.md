# Offline password blocklist

`common-passwords.txt` is SecLists' `Passwords/Common-Credentials/10k-most-common.txt`, downloaded 29 October 2026.

Source: https://github.com/danielmiessler/SecLists

License: MIT. Preserve the upstream license in `SECLISTS_LICENSE.txt`.

The list is an offline baseline of known common credentials. It is not a claim that every breached password is covered. Add reviewed, versioned compromised-password entries as the threat model evolves; never send plaintext passwords to an external service.
