# Phase 3 API and acceptance coverage

29 October 2026. This is the local P1 backend implementation/acceptance inventory; Phase 4's independent verification gate has not been passed by this inventory. Paths are relative to `/api/v1/businesses/{business_id}`. FR, UC and TC numbers share the same numeric suffix in the approved SRS. The saved OpenAPI defines concrete schemas; `test_api_surface.py` checks success/error contracts, typed report retrieval and frontend-facing reads/actions.

- **FR/UC/TC-005 and 006:** `/parties`, `/trade-documents`, `/source-drafts`, `/payments`, `/advances`, `/parties/{id}/statement`. Golden tests: `test_invoice_partial_payment_and_cash_timing`, `test_bill_two_payments_and_loan_principal`, `test_credit_refund_reconciles_and_cannot_refund_twice`, `test_advance_application_and_reminder_settlement_recheck`, `test_source_drafts_are_unposted_until_issued_and_voids_never_post`, `test_party_statement_history_and_held_beneficiary_changes`.
- **007:** Payment allocations, explicit settlement fees, dispute status and `/reminders/review`. Tests cover partial/multiple payments, refunds, advance application, no duplicate reminders after settlement, and fee separation. P1 reminders are in-app; external delivery remains P2.
- **008 and 010:** `/bank-imports/preview`, `/bank-imports`, `/bank-transactions`, disposition/preview/matches/reclassifications. Tests: `test_bank_reimport_preserves_legitimate_identical_rows`, `test_bank_split_match_and_two_sided_transfer_do_not_duplicate_profit`, `test_many_to_one_bank_match_and_reclassification_preserve_source_totals`. Unknown rows remain unposted; source journals are matched without reposting.
- **009:** Evidence upload/list/detail/download/notes/links/capabilities, reviewed identity/duplicate candidates and `/jobs`. Real scanner/OCR/quarantine/upload tests retain their evidence. `test_phase3_closure.py` checks normalized supplier/date/currency/total candidates from distinct originals and no automatic merge. `test_phase3_edges.py` checks exhausted retries, authorized replay and successful rescan. English extraction/manual fallbacks are defined in `document-extraction.md`.
- **011:** `/loans`, `/loans/{id}/movements` and role-separated party statements. Test: `test_bill_two_payments_and_loan_principal`. Principal, interest and fees use separate accounts; over-repayment is rejected.
- **012:** Transfer/card dispositions with explicit clearing. Paired/late transfer tests preserve combined cash/profit and history. `test_card_settlement.py` checks paired card debt clearance, unchanged purchase expense, consumed-side rejection and invalid direction. Phase 4 expands adversarial/concurrency coverage.
- **013 and 028:** `/statements/sign-off`, `/exports/evidence-pack.zip`, `/exports/verification-key`. Test: `test_real_scanner_statement_and_signed_offline_export`. Real scan, nonzero-difference rejection, offline relative paths, every file hash and Ed25519 signature are checked.
- **014 and 017:** GL/trial-balance, typed financial/aging/control/tax/forecast/dashboard reports, history list/detail and saved-report answers. Existing golden tests verify cash timing, tax and source tie-outs. `test_api_surface.py` verifies all report families, immutable retrieval, thirteen-week due-date totals, explicit unavailable bands, missing/invalid numeric tools and no actions, duplicate cash selections and date overflow. Opening-policy tests verify source-reviewed cash recognition and prior-recognized treatment. Forecast remains a disclosed deterministic baseline.
- **015 and 026:** Rule preview/approve/pause/rollback, deterministic transaction proposals and `/bank-rules/correction-suggestions`. Existing rule test enforces preview and no autoposting. `test_phase3_closure.py` verifies draft suggestions supported by distinct latest corrections and normalized descriptors. Only active income/expense targets are proposed; raw source text is retained. External enrichment/autoposting remain later scope.
- **025:** `/parties/{id}/beneficiary-changes`, `/beneficiary-changes`. Test: `test_party_statement_history_and_held_beneficiary_changes`. Proposals are encrypted, masked, idempotent and permanently held in P1. No payment execution or independent ownership verification is asserted.
- **033 and 044:** Entitlement/usage, file/storage/import/operation limits, durable retries/replay and retained export caps. `test_phase3_edges.py` verifies trial expiry denies writes while retaining read/export/privacy fulfillment, configured row/file limits and the three-snapshot cap; failed-job replay requires quarantine and does not replay completed work. No live charges or automatic paid upgrade. Phase 4 independently expands concurrency/load/failure verification.
- **034 and 035:** Notifications/preferences, `/jobs`, reasoned replay, `/audit-events`, `/readiness`. Membership administration stays scoped; there is no unrestricted support impersonation. Close/membership and scanner-outage tests exercise selected authorization and failure paths.
- **037 and 039:** Search, reviewed imports, opening balances/corrections/cash policy/history, parallel comparison, safe CSV and retained resumable snapshots. Existing import/opening tests verify atomic baselines and preserve old hashes/retries. `test_opening_corrections.py` verifies immutable corrections, source-specific retry keys, control balances and evidence-backed cash policies. `test_phase3_closure.py` verifies exact resumed bytes after new postings, checksum/ETag, ownership, invalid ranges, expiry and expired-artifact cleanup. Larger selections use bounded date windows; no unbounded export claim.
- **038:** Own consent/request/export, owner/accountant review queue, independent review decisions and scoped request history. Existing export checks exclude credentials. Closure/edge tests verify independent approval, requester-visible current outcome, authenticated export readiness and retained access after trial expiry. P1 records policy references/categories/date/hold; it never marks a review as erased data. P2 automated processor/backup/deletion execution stays outside this release.
- **040:** `/close-tasks` and `/readiness`. Test: `test_close_requires_independent_reviewer_and_membership_changes_are_scoped`. Required tasks block period close; preparer cannot approve their own work.
